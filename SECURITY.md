# Security policy

Do not report a compromised plugin release or leaked signing key in a public issue. Use GitHub's
private security advisory form for this repository.

Include the plugin ID, affected versions, evidence, and a safe contact address. Maintainers can mark
a release `revoked`, publish the reason and replacement version, and prevent new installations.
qrate warns users; it does not automatically delete plugin code or data.

Rotate a compromised catalog key according to [PUBLISHING.md](PUBLISHING.md). A registry listing
does not transfer responsibility for plugin support or security from its publisher.
